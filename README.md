# Firmenwebsite

Website für Anwaltskanzleien. Projektregeln und offene Punkte: siehe `CLAUDE.md`.

```bash
npm ci          # Abhängigkeiten installieren
npm run dev     # Entwicklung auf http://localhost:3000
npm run build   # Produktions-Build
npm run lint    # Code prüfen
```

Texte ändern: `lib/content.ts` · Name, Kontakt, Impressum: `lib/site-config.ts` ·
Farben: `app/globals.css`
